🚀 HOW TO EXECUTE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Choose ONE of these three methods:

┌─ METHOD 1: SQL EDITOR (EASIEST FOR FIRST-TIME) ─────────────────────────┐
│                                                                          │
│ 1. Go to: https://app.supabase.com → your project                       │
│ 2. Click: SQL Editor → New Query                                        │
│ 3. Open: /workspaces/GuardTech/migrate_to_supabase.sql                  │
│ 4. Copy all content                                                      │
│ 5. Paste into SQL Editor                                                │
│ 6. Click: Run                                                            │
│ 7. ✅ Done! Tables created automatically                                 │
│                                                                          │
│ Time: ~30 seconds                                                        │
│ Requirements: Browser only                                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ METHOD 2: BASH SCRIPT (AUTOMATED, RECOMMENDED) ────────────────────────┐
│                                                                          │
│ 1. Get connection string:                                                │
│    Supabase Dashboard → Settings → Database → Connection Pooling        │
│    Copy the postgresql:// URL                                           │
│                                                                          │
│ 2. Set environment variable:                                            │
│    export DATABASE_URL="postgresql://postgres.[id]:[pass]@..."         │
│                                                                          │
│ 3. Run script:                                                           │
│    /workspaces/GuardTech/run_migration.sh                               │
│                                                                          │
│ 4. ✅ Done! Script handles everything including verification            │
│                                                                          │
│ Time: ~1 minute (includes dependency checks)                            │
│ Requirements: Terminal + PostgreSQL client                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘

┌─ METHOD 3: PYTHON SCRIPT (ADVANCED) ───────────────────────────────────┐
│                                                                          │
│ 1. Install dependencies:                                                │
│    pip install psycopg2-binary python-dotenv                            │
│                                                                          │
│ 2. Set environment variable:                                            │
│    export DATABASE_URL="postgresql://..."                               │
│                                                                          │
│ 3. Run script:                                                           │
│    python3 /workspaces/GuardTech/migrate_supabase.py                    │
│                                                                          │
│ 4. ✅ Done! Script shows verification details                           │
│                                                                          │
│ Time: ~1 minute                                                          │
│ Requirements: Python 3.8+ with psycopg2                                 │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────┘
