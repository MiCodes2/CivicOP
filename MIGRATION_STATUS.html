Method 2: Bash Script (⭐ Recommended for Automation)

Effort: 2 minutes | Requirements: Terminal, PostgreSQL client

  1. Get connection string from: Supabase Dashboard → Settings → Database → Connection Pooling
  2. Copy the postgresql:// URL
  3. Set environment variable:
    export DATABASE_URL="postgresql://postgres.[id]:[pass]@aws-0-region.pooler.supabase.com:6543/postgres"
  4. Run the script:
    /workspaces/GuardTech/run_migration.sh
  5. ✅ Script handles everything including verification!

Method 3: Python Script (For Advanced Users)

Effort: 3 minutes | Requirements: Python 3.8+, pip

  1. Install dependencies:
    pip install psycopg2-binary python-dotenv
  2. Set environment variable:
    export DATABASE_URL="postgresql://postgres.[id]:[pass]@aws-0-region.pooler.supabase.com:6543/postgres"
  3. Run the script:
    python3 /workspaces/GuardTech/migrate_supabase.py
